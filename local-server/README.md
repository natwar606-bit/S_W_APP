# Local Server for Shree Sawariya Traders Billing Software

This folder contains the local Node.js / Python static file server and local utility scripts.

These files are for local offline usage only and are excluded from Vercel deployments via `.vercelignore`.

## Usage
- Run `start.bat` to launch the local billing software at `http://localhost:8080`.
- Run `stop.bat` to shut down the server running on port 8080.
- Run `create-desktop-shortcut.bat` to create a one-click desktop shortcut on Windows.
